# 002. Expo dev build, not Expo Go

- **Status:** Accepted
- **Date:** 2026-10-17
- **Requirements:** FR-01, FR-06, NFR-01, NFR-04

## Context

The app needs native modules that Expo Go does not include: Vosk for offline Hindi speech
(`react-native-vosk`), SQLCipher for the encrypted database, and an on-device safety-gear detector.

## Decision

Build the Android app as an Expo **development build** (`npx expo run:android`, EAS Build for
releases). Native folders are generated by prebuild and are not committed.

## Consequences

- We keep Expo's tooling and libraries while using native modules.
- Every developer needs Android Studio and JDK 17, and a rebuild after any native change.
- The Sprint 0 spike must prove that Vosk, the camera, SQLCipher and the detector work together in
  one build on the 3 GB target phone. Fallback: run the safety-gear check on the server after sync.
